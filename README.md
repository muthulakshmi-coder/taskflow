# TaskFlow – Kanban Board (Week 1)

A static Kanban board layout built with semantic HTML and CSS Grid, part of the SkillMe Web Development Internship.

## What's included
- Header with app name and a non-functional "Add task" form (title, priority, button)
- Three columns: To Do, In Progress, Done, each with a task count
- Six sample task cards with priority labels (Low, Medium, High) and due dates
- Colours managed with CSS variables
- Responsive: columns stack on screens narrower than 700px

## Run it
Open `index.html` in any browser. No build step needed.

## Project structure
```
index.html   page structure
style.css    layout and styling
script.js    placeholder for Week 2
```

## Roadmap
- Week 1: Layout with HTML and CSS (done)
- Week 2: Add, move and delete tasks with JavaScript
- Week 3: Save tasks and import starter data
- Week 4: Drag-and-drop, polish and deploy
